# Agent 记忆与个性化（千人千面）

> **一句话**：Agent 的记忆分两层——**短期记忆**就是当前对话的上下文窗口，**长期记忆**是把跨会话有用的事实（用户是谁、偏好什么、上次聊了什么）沉淀到外部存储，用的时候检索注入。简历场景「正负样本与记忆提取实现千人千面 + 上下文改写标准化用户输入」= 长期记忆的**提取→存储→注入**闭环 + 入口的**查询标准化**，两件武器合起来就是个性化问答的完整答案。

## 1. 记忆的分层模型

```
短期记忆（Working Memory）：当前会话上下文窗口
   │ 满了/结束了怎么办？↓ 提取有价值的信息
长期记忆（Long-Term Memory）：
   ├─ 用户画像（静态）：角色、行业、常用口径
   ├─ 事实记忆（ эпisodic）：上次问过什么、结论是什么
   └─ 偏好/反馈（正负样本）：点赞的答案风格、点踩的错误
        ↑ 用的时候按相关性检索，注入 system prompt / 上下文
```

- 灵感源头 MemGPT：像操作系统一样把上下文窗口当"内存"、外部存储当"磁盘"，模型自己决定何时换入换出（分页）——与 Manus「文件系统即外部记忆」同一思想。

## 2. 千人千面的工程闭环（简历场景展开）

| 环节 | 做法 |
|---|---|
| 记忆提取 | 会话结束后用 LLM 抽取结构化事实（"该教师教初二数学，偏好图表化答案"），去重合并入向量库/结构化表 |
| 记忆注入 | 新会话按用户 ID + 当前问题检索相关记忆，注入 system prompt（控制条数防撑爆上下文） |
| 正负样本 | 用户点赞/点踩 → 正例进"偏好记忆"，负例（badcase）进评测集与负样本库，既做检索过滤也做微调数据 |
| 权限隔离 | 记忆按用户隔离（政务/教育场景强合规要求），敏感信息脱敏后再存 |
| 记忆遗忘 | 支持用户查看/删除自己的记忆（合规 + 防过时记忆污染） |

## 3. 上下文改写（Query Rewrite / 标准化）

多轮对话的第一道工序，直接影响检索与理解质量：
- **指代消解**："那它呢？" → 结合历史改写成完整独立问题；
- **口语标准化**：方言/简称/错别字 → 标准术语（"补多少money" → "补贴金额是多少"），教育场景学生提问尤其需要；
- **查询扩展**：同义词/上下位词扩展提升召回（配合 RAG）；
- 实现：小模型即可胜任（分类/改写任务用微调小模型，成本低时延低——呼应多模型路由）。

## 4. 高频面试题

1. 短期记忆和长期记忆分别怎么实现？（上下文窗口 vs 外部存储+检索注入；窗口管理参考 MemGPT/文件系统记忆）
2. 记忆越存越多怎么控制？（相关性检索只注入 Top-K、时效衰减、去重合并、用户可管理）
3. 个性化与隐私怎么平衡？（隔离、脱敏、可查看可删除、政务场景本地化部署）
4. 记忆注入后提示词变长怎么办？（只注入选中字段、压缩摘要、前缀缓存——system 结构保持稳定）
