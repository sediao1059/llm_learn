# llm_learn — 大模型技术学习仓库

个人大模型（LLM）技术学习项目：**知识点笔记 + 可交互知识图谱 + AI 全局助手**。

**作者**：色调 · 联系邮箱：[sediao666@qq.com](mailto:sediao666@qq.com)

> **贡献者 / AI 助手必读**：修改本项目任何代码前，先读 [AGENTS.md](AGENTS.md)（协作规范）与 [SPEC.md](SPEC.md)（产品需求规范，本项目功能需求的唯一事实来源）。

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | **NestJS 10 + Prisma + MySQL**（TypeScript，46 个源文件） |
| 前端 | **React 18 + Ant Design 5 + Vite**（TypeScript，28 个源文件） |
| 图谱 | ECharts 5 |
| LLM | 双协议客户端（openai 兼容 / anthropic），SSE 流式 |

## 快速启动

```bash
# 1. 后端
cd backend
cp .env.example .env   # 编辑数据库连接
npm install
npx prisma db push
npm run start:dev       # → http://127.0.0.1:8080/api

# 2. 前端
cd frontend
npm install
npm run dev             # → http://127.0.0.1:3000
```

## 部署（llm.fixbug.fun）

线上环境：阿里云 CentOS 7（139.196.151.20），部署目录 `/usr/local/llm_learn`，MySQL 5.7（同机 Docker），nginx 托管前端静态资源并反代 `/api`。

> 服务器两条红线决定了部署形态：① CentOS 7 的 glibc 2.17 跑不了原生 Node 18+/Prisma 6；② Docker 1.13（glibc 2.36 的 bookworm 容器会因 `clone3` 系统调用被老 seccomp 拦截而崩）。因此后端构建与运行都在 **`node:20-bullseye-slim` 容器**里（glibc 2.31 兼容），镜像由 `deploy.sh` 在服务器缺失时自动「本地拉取 → save → ssh load」导入（老 Docker 拉不动新镜像）。

```bash
./deploy.sh back    # rsync 后端源码 → 服务器容器内 npm install/构建/db push → 重启容器
./deploy.sh front   # 本地构建前端 → rsync dist
./deploy.sh all     # back + front
```

- 前置：本机已配 SSH 公钥免密登录 root@139.196.151.20；服务器 `/usr/local/llm_learn/backend/.env`（DATABASE_URL / JWT_SECRET / PORT，人工维护、不入库）。
- 每次 `back` 部署自动执行：`prisma db push`（幂等同步表结构）。手工笔记存 MySQL（管理页「笔记管理」编辑，SPEC §4.19），部署不再同步文件。
- 后端容器 `llm-learn-backend`（`--restart unless-stopped`），与 mysql 容器同在 `llm-net` 网络（数据库主机名 `mysql`），仅监听 `127.0.0.1:9100`；nginx 配置在 `/etc/nginx/conf.d/llm.fixbug.fun.conf`（`/api/` 反代已为 SSE 关闭缓冲）。
- 注意：编译产物在 `dist/src/main.js`（运行入口）。
- **数据库备份**（2026-10-22 起）：服务器 `/etc/cron.d/llm-learn-backup` 每天 05:00 执行 `/usr/local/llm_learn/backup.sh`（mysql 容器内 mysqldump → gzip），产物在 `/usr/local/llm_learn/backups/`，**保留 30 天**自动清理；备份自带建库语句，恢复命令：`gunzip < llm_learn-*.sql.gz | docker exec -i mysql mysql -uroot -p`。注意备份与库同盘，重要数据建议定期把备份文件拉回本地一份。

## 主要功能

- **知识图谱**：ECharts 力导向图，「🌱 起点」默认按根节点 + 2/3/4 层聚焦呈现（新用户自动用全图最枢纽的节点当起点，可自选任意知识作起点、跟账号持久化，可临时看全部；有筛选条件时自动全图命中，不因聚焦层数漏掉与已有知识零关联的孤岛专栏）；左上角「筛选」（默认折叠收起，徽标显示生效条件数）可按关键词 / 标签 / 难度（入门·进阶·深入·未标注）AND 叠加缩小范围，筛选条件与底部分类图例（彩色按钮）的显隐状态刷新后自动保持（点「清空筛选」才重置）、0 命中有大白话提示；**点选聚焦**——点击节点即红框高亮放大，一跳邻居保持清晰、相关连线转红加粗，无关节点缩小淡化让位、相关节点聚拢铺开（关闭笔记浮窗自动还原）；点击节点打开笔记 Drawer（Markdown 渲染 + 划词注解 + 标题栏 🤖 一键面向整篇向 AI 追问（多轮流式、带笔记正文上下文，解答存为整篇注解；回答还可「✨ 沉淀为知识点」进图谱——AI 顺带判断是否与本篇相关并建立图谱关联，判断结果在预览/审核里可人工修改）+ 底部「💬 全部注解」总入口（汇总本篇划词/整篇/面试题，点任意条目进讨论区；学习程度右对齐）+ 放大阅读 + 学习程度标记）；画布空白处按住拖拽即平移（全画布生效）、滚轮缩放；注解以知乎风荧光高亮内嵌在正文中（已审核=黄色高亮 / 自己待审核=高亮+橙虚线，高频面试题带 💼），点击高亮弹出注解阅读弹窗，弹窗内是知乎式讨论区——可针对整条注解向 AI 提问（SSE 流式，问答对沉淀共享）或发表评论（即时全员可见）；关联知识点标签点击即在抽屉内跳转打开；未生成面试题的笔记在正文末尾点击即 AI 流式出题（生成完自动转入注解阅读弹窗，全员共享、下次秒开；别的用户正在生成同一篇时直接实时共享那一次输出，不重复调模型；「重新生成」仅管理员可见）
- **学习路线**：左侧路线卡片（进度圆环）+ 右侧树形学习视图（阶段折叠 + 主题标记 + 路线内导航），AI 定制/调整（按学习目标语义检索出最相关的知识点作**可选参考**，贴合才引用、不合适就自拟主题，不强行对齐知识库——新手也能拿到看得懂的路线），支持知识点扩展加入路线；列表只显示官方路线与自己创建的路线（私人路线仅创建者与管理员可见）；路线卡片支持删除（普通路线限创建者或管理员，官方路线仅管理员）；「新主题」点击即懒加载——SSE 流式生成 markdown 学习内容（边流边渲染），生成后缓存进路线、下次秒开，可重新生成（别的用户正在生成同一主题时直接实时共享那一次输出，不重复调模型）；生成的内容同样支持划词注解（选中→💡解答→存注解→荧光高亮阅读，与图谱笔记一致）
- **AI 助手（顶栏 💬）**：右侧滑出抽屉，个人会话池（仅自己可见，可续聊/重命名/删除）；SSE 流式打字机输出（💭 思考过程折叠展示），对话模型可临时切换并本地记忆；回答风格默认精简（先给核心答案 + 几个要点，追问再展开细节与代码）；每条回答可「✨ 沉淀为知识点」（当轮回答完成即出现按钮）——AI 只提取标题（顺带分类/标签），回答原文直接做正文：管理员预览（标题可改）→ 确认直写图谱，普通用户填星级表单提交审核（进度看顶栏「📥 沉淀」）；整篇追问（知识浮窗 🤖）的回答走同一套沉淀流程，AI 会顺带判断并与被追问的笔记建立关联，沉淀出的节点不再是图谱孤岛；抽屉右上角「⛶」可放大成宽屏看长回答（偏好自动记住）
- **模型调用排队**：同一模型同时最多 3 个调用（`LLM_MODEL_CONCURRENCY` 可调），超出的先来先得排队——界面提示「前面还有 N 个任务、预计等待约 M 秒」（按该模型最近耗时滚动平均预估），排到后自动继续；关闭页面/浏览器立刻取消自己的排队并中止运行中的调用，把并发额度让给别人；上传 AI 拆解等后台任务不受关页面影响，照常排队执行
- **个人学习工具（顶栏）**：🕘 足迹（最近浏览 200 条，点行原地打开那篇笔记浮窗，不跳转图谱页）/ ⭐ 收藏（笔记面板 ☆ 一键收藏，点整行原地打开笔记浮窗，跨设备跟随账号）/ 💡 注解（我划词沉淀过的全部注解，含审核状态）/ 📥 沉淀（我提交的知识点进度）
- **上传知识**：链接 / 文本 / 文件 → AI 拆解成知识点 → 管理员审核 → 专栏入库，贡献计分；文件支持**多张图片**（png/jpg/webp，单张 <5M、上传后自动压缩，一次最多 9 张）与 **Word 附件**（.docx，连文中插图一并解析，最多前 10 张）——图片交给管理员配置的**多模态模型**看图拆解，原图保留在知识内容里图文对照；审核通过后每条知识作为「📤 上传」节点进图谱——连向所属「📚 专栏」聚合节点（两者分类/色块独立，一眼分清谁是专栏谁是子知识）、同批多条互相关联、保留与已有知识点的关联（审核时即时挂载 + 每日定时任务幂等兜底，任务只做数据库写入不调 AI）；AI 拆解保存后立刻就能点开阅读拆解出的每篇内容（审核通过前仅自己可见）；「📋 我的提交」页（顶栏入口）查看全部上传记录、审核状态与驳回理由，点击条目打开阅读浮窗；**专栏导航**——打开「📚 专栏」浮窗，成员文章按 1、2、3 序号单列为「📚 专栏文章」（点击即读，不再混入关联知识点）；打开专栏里的文章，顶部显示「📚 所属专栏」标签、标题旁有「返回专栏」一键回到专栏
- **知识库（顶栏 📚）**：表格形式浏览全部知识（静态笔记 + ✨ AI 沉淀），筛选四条件可叠加：关键词（搜标题/摘要/分类/层次/标签）× 分类 × 难度（入门/进阶/深入/未标注）× 掌握程度（登录后按自己的学习程度标注过滤），条件刷新后保持、可一键清空；点击行打开与图谱页相同的笔记浮窗（划词注解/收藏/学习程度全可用）；管理员可在难度/层次列直接下拉补标（手工笔记与 AI 沉淀/上传/专栏节点都行，AI 沉淀默认未标注）
- **最近更新（顶栏 🆕）**：全站知识按更新/新增时间从新到旧排列（接口实时查 MySQL），标明动态类型（新增 / 更新 / 收到 AI 补充）与来源（📝 手工笔记 / ✨ AI 沉淀 / 📤 上传知识 / 📚 专栏），可按来源筛选；游客可见手工笔记部分，登录后合并 AI 沉淀；点击行打开与图谱页相同的笔记浮窗
- **新手引导（顶栏 💡 灯泡）**：两段式新手引导——未登录首次打开首页自动播放（怎么看知识图谱、筛选、去哪提反馈、为什么登录注册）；登录/注册成功后自动播放第二段（官方学习路线怎么看、AI 定制专属路线、AI 助手抽屉与划词注解现场演示，纯界面示意不调用模型），跨页面自动跳转；右上角灯泡随时点击重看（未登录时闪烁提醒，登录后不闪），看过一次不再自动弹出
- **用户反馈（顶栏 💬）**：登录前后都能提意见/报 bug（登录后自动关联账号，游客可留联系方式），公开提交接口带 IP 限流防刷；管理页「💬 反馈」页签查看与删除
- **管理中心**（12 个页签）：用户（含 AI 禁用/用量统计/👑 超级管理员保护）/ ⚙ 模型配置（双协议 CRUD、真发一句话测试连接、全局默认互斥切换、多模态默认——上传图片/Word 插图解析专用，同供应商换个模型 ID 即可如 GLM-5.3-Flash）/ 邀请码 / 沉淀审核 / 上传审核 / 面试题 / 学习路线 / 定时任务 / 版本管理 / 报表统计 / **笔记管理（手工笔记增删改查，MySQL 唯一创作源头；正文 Markdown 编辑+预览，保存自动提取一句话摘要与面试题注解、图谱即时刷新）** / 💬 反馈
- **用户体系**：注册（邀请码 + 画像 + 默认路线）/ 登录（可勾选记住账号密码，存本机浏览器）/ 角色（第一个注册的用户是超级管理员，不可禁用/不可撤管；其他管理员由管理页分配）/ 禁用 / AI 禁用 / 资料编辑 / 管理员备注（管理页用户管理可给用户写一条仅管理员可见的备注）
- **版本管理**：顶栏版本徽章（hover 浮窗展示**最近 3 个版本**的更新内容，分组呈现）+ 管理端 CRUD（发布/编辑时一个「对用户可见」开关——关闭则该版本仅管理员可见 🔒，用户徽章与公开接口整条不出现）；**发布记录自动登记**——每个功能性更新在 `backend/version.releases.json` 台账登记一条（大 major / 中 minor / 小 patch 三档），部署后后端启动时自动写入版本管理（按内容指纹幂等，多环境/并发不重复不重号；纯 UI 微调、仅管理员功能/配置、部署与开发运维向改动不必登记）
- **手机 / iPad 适配**：窄屏（<1024px，iPad 竖屏及以下）自动切换移动布局——顶栏导航收进 ☰ 汉堡抽屉、功能按钮图标化、用户区收进 👤 下拉；手机端笔记浮窗 / AI 助手 / 学习内容抽屉全屏（助手会话列表由「☰ 会话」按钮唤出）；图谱画布支持触屏单指拖拽平移 + 双指捏合缩放；学习路线页与上传页改单列（路线列表收成顶部下拉）；各页表格窄屏横向滑动；桌面端（≥1024px）布局与交互完全不变
